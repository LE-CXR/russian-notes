Урок 6 · 复数各格 мно́жественное число́

对应《走遍俄罗斯》第 2 册第 6 课（стр. 178）· 语法核心：名词复数六个格 + 代词形容词复数 + 泛指人称句 + который / е́сли / хотя́ 从句

这一课是全册的收口。前五课一格一格学的是单数，现在把它们整体放大到复数。注意一个关键事实：复数的格词尾比单数简单得多——复数不区分阳阴中，只分「辅音结尾」和「软结尾（-ь / -й / -я）」两类。

格词尾例（стол / кни́га / окно́）
一格-ы / -и / -а / -ястолы́ · кни́ги · о́кна
二格（最难）-ов / -ев / -ей / 零词尾столо́в · книг · о́кон
三格-ам / -ямстола́м · кни́гам · о́кнам
四格非动物 = 一格；动物 = 二格столы́（非动物）· студе́нтов（动物）
五格-ами / -ямистола́ми · кни́гами · о́кнами
六格-ах / -яхстола́х · кни́гах · о́кнах

先记三格、五格、六格——它们是送分的。-ам / -ами / -ах（硬）与 -ям / -ями / -ях（软）六种形式覆盖全部名词，没有例外需要操心。真正要花时间的是二格复数，那是俄语所有格变化里最难的一处。

一、复数一格（复习）

类型词尾例
阳 硬辅音-ыстуде́нт → студе́нты · стол → столы́ · го́род → города́（重音移动）
阳 г/к/х/ж/ш/ч/щ-икни́га → кни́ги · врач → врачи́ · каранда́ш → карандаши́
阳 -й / -ь-имузе́й → музе́и · слова́рь → словари́
阴 -а-ы（г/к/х 后 -и）ка́рта → ка́рты · де́вушка → де́вушки
阴 -я / -ь-инеде́ля → неде́ли · пло́щадь → пло́щади
中 -о-аокно́ → о́кна · ме́сто → места́
中 -е / -ие-я / -иямо́ре → моря́ · зда́ние → зда́ния

二、复数二格（本课重点，也是全册最难）

类型词尾例
阳 硬辅音-овстуде́нт → студе́нтов · стол → столо́в · го́род → городо́в
阳 ж/ш/ч/щ-ейврач → враче́й · каранда́ш → карандаше́й · това́рищ → това́рищей
阳 -й-евмузе́й → музе́ев · трамва́й → трамва́ев
阳 -ь-ейслова́рь → словаре́й · писа́тель → писа́телей
阴 -а零词尾кни́га → книг · ка́рта → карт · де́вушка → де́вушек（插入元音）
阴 -я-ь（零）неде́ля → неде́ль · дере́вня → дереве́нь
阴 -ь-ейпло́щадь → площаде́й · тетра́дь → тетра́дей
中 -о零词尾окно́ → о́кон · ме́сто → мест
中 -е-еймо́ре → море́й · зда́ние → зда́ний（-ие → -ий）

三个必须单独记的规律

  1. 阴性 -а 一律零词尾：кни́га → книг、рабо́та → работ、газе́та → газе́т。不要写 кни́гов。
  2. ж/ш/ч/щ 后面写 -ей 不写 -ов：врач → враче́й（不是 врачо́в）、каранда́ш → карандаше́й。
  3. 插入元音 о/е：词干以两个辅音结尾时，为了好读要插一个元音——де́вушка → де́вушек、окно́ → о́кон、письмо́ → пи́сем。

三、四格、五格、六格复数

格规则例
四格非动物 = 一格；动物 = 二格Я ви́жу столы́（非动物，同格）· Я ви́жу студе́нтов（动物，同二格）
五格-ами / -ямистола́ми · кни́гами · детьми́（特殊）
六格-ах / -яхо стола́х · в кни́гах · о детя́х

四格的「动物 / 非动物」规则和单数完全一样，只是这次作用于复数。Я ви́жу де́вушек（看见姑娘们，动物→二格）· Я ви́жу кни́ги（看见书，非动物→一格）。

形容词与代词复数

格形容词例
一格-ые / -иено́вые студе́нты · сосе́дние до́мы
二格-ых / -ихно́вых студе́нтов
三格-ым / -имно́вым студе́нтам
四格非动物 -ые/-ие；动物 -ых/-ихно́вые кни́ги · но́вых друзе́й
五格-ыми / -имино́выми студе́нтами
六格-ых / -ихо но́вых студе́нтах

四、泛指人称句

施事者不出现、或者指「人们、大家」时，动词用复数第三人称，句子里没有主语。这是俄语里的常用句式，中文常译成「有人……」「大家……」或干脆省掉。

Моско́вское метро́ откры́ли в 1935 году́. — 莫斯科地铁 1935 年开通。
Э́тот фильм пока́зывают в кино́. — 这部电影正在影院上映。
В э́том музе́е мо́жно посмотре́ть карти́ны изве́стных худо́жников. — 在这个博物馆可以看到著名画家的画。

五、三个从句连接词

连接词意义例
кото́рый定语从句（……的）Я зна́ю студе́нтов, кото́рые у́чатся здесь. — 我认识在这里读书的学生们。
е́сли如果（条件）Е́сли мой друг сдаст экза́мены, он посту́пит в институ́т.
хотя́虽然（让步）Хотя́ я живу́ в Москве́ то́лько не́сколько ме́сяцев, я уже́ непло́хо зна́ю её.

六、28 个例句（全部标重音）

A. 二格复数（9 句）

  1. В гру́ппе мно́го студе́нтов. — 班里有很多学生。
  2. В музе́е мно́го карти́н. — 博物馆里有很多画。
  3. У нас нет свобо́дных мест. — 我们没有空位。
  4. Здесь рабо́тают мно́го враче́й. — 这里有很多医生工作。
  5. Я не зна́ю э́тих люде́й. — 我不认识这些人。
  6. Он рабо́тает здесь пять лет. — 他在这里工作五年了。
  7. В го́роде мно́го краси́вых пло́щадей. — 城市里有很多漂亮的广场。
  8. Э́то общежи́тие для студе́нтов и преподава́телей. — 这是学生和教师宿舍。
  9. Ско́лько дете́й в ва́шей семье́? — 你们家有几个孩子？

B. 三格、五格、六格复数（7 句）

  1. Она́ помога́ет де́тям де́лать уро́ки. — 她帮孩子们做作业。
  2. Я звоню́ роди́телям ка́ждую неде́лю. — 我每周给父母打电话。
  3. Он познако́мился с но́выми друзья́ми. — 他结识了新朋友。
  4. Мы говори́ли с преподава́телями. — 我们和老师们谈过。
  5. Я люблю́ чита́ть о ру́сских города́х. — 我喜欢读关于俄罗斯城市的书。
  6. Э́то кни́ги о вели́ких худо́жниках. — 这些是关于伟大画家的书。
  7. Он интересу́ется ру́сскими тра́дициями. — 他对俄罗斯传统感兴趣。

C. 四格复数与泛指人称（5 句）

  1. Я ви́жу студе́нтов и студе́нток. — 我看见学生们。
  2. Я чита́ю интере́сные кни́ги. — 我在读有趣的书。
  3. Он зна́ет э́тих де́вушек. — 他认识这些姑娘。
  4. Моско́вское метро́ откры́ли в 1935 году́. — 莫斯科地铁 1935 年开通。
  5. В э́том рестора́не хорошо́ гото́вят. — 这家餐厅做菜很好。

D. 从句（7 句）

  1. Я зна́ю студе́нтов, кото́рые у́чатся здесь. — 我认识在这里读书的学生。
  2. Вот дома́, в кото́рых живу́т мои́ друзья́ и́ли их роди́тели. — 这就是我朋友或他们父母住的房子。
  3. Е́сли мой друг сдаст экза́мены, он посту́пит в институ́т. — 如果我朋友通过考试，他就上大学。
  4. Хотя́ я живу́ в Москве́ то́лько не́сколько ме́сяцев, я уже́ непло́хо зна́ю её. — 虽然我在莫斯科只住了几个月，但已经挺了解它了。
  5. Я хочу́, что́бы вы зна́ли э́тих люде́й. — 我想让你们认识这些人。
  6. Е́сли у тебя́ есть вре́мя, приходи́ ве́чером. — 如果你有时间，晚上来。
  7. Он сказа́л, что прие́дет за́втра с друзья́ми. — 他说他明天和朋友们一起来。

自查三问（做复数题前默念）

  1. 这是哪个格？先定格，再定词尾——复数不区分性，只看格。
  2. 如果是二格：词干是不是 ж/ш/ч/щ 结尾？是不是两个辅音结尾（要插元音）？
  3. 如果是四格：这个名词是动物吗？动物就借二格的形式。

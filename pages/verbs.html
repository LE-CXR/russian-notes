未完成体 НСВ · 完成体 СВ

НСВ 未完成体 несовершенный вид

  • 过程：正在做、持续做
  • 重复 / 习惯：经常、总是
  • 能力 / 一般事实
  • 现在时只有 НСВ
  • 将来时用 буду + 不定式

Я чита́ю кни́гу.（我在看书）

Ка́ждый день я пишу́ пи́сьма.（我每天写信）

СВ 完成体 совершенный вид

  • 结果：做完、做成
  • 一次性具体行为
  • 开始 / 结束某动作
  • 没有真正的现在时
  • 变位形式表示将来完成

Я прочита́л кни́гу.（我看完了这本书）

За́втра я напишу́ письмо́.（明天我把信写完）

怎么判断及物 / 不及物

别死记「及物=永远四格」。先问：这个动词后面能不能直接接 кого́? / что?（把谁 / 把什么）。能接，多半是及物；不能，就看它固定支配几格。

10 秒清单

  1. 能不能问 кого́? что?？能 → 通常及物 + 四格（如 чита́ть кни́гу）。
  2. 问不了「把谁/把什么」，却能问 кому́? / с кем? / где? → 不及物或固定支配，跟动词走。
  3. 查一眼例外表（下面）：否定、帮助、从事……经常不是四格。

常见例外（不是「永远四格」）

情况几格例记住
动词固定 + 三格 3 помога́ть дру́гу · звони́ть ма́ме 帮助 / 打电话 → кому́?
动词固定 + 五格 5 занима́ться спо́ртом · встреча́ться с дру́гом 从事 / 与谁 → чем? / с кем?
否定「没有」 2 Нет вре́мени. · У меня́ нет кни́ги. нет / не́ было → 二格

口诀：先问 кого́?/что?；问不通就查支配；否定有/没有优先想二格。

三格 vs 四格 · 速记

三格 кому́? чему́?

「给谁 / 对谁」——对象、受益者

  • дать / помога́ть / звони́ть / нра́виться
  • говори́ть / сказа́ть кому́
  • к + 三格：к врачу́

四格 кого́? что?

「把什么 / 看见谁」——直接宾语

  • ви́деть / люби́ть / спроси́ть / чита́ть / жда́ть
  • писа́ть / смотре́ть / понима́ть / де́лать
  • в/на + 四格 = куда?（方向）

双支配口诀：把什么（四格）给谁（三格）—— дать / показа́ть / рассказа́ть / бро́сить。

二格高频：у кого́? · нет + 2 · из/с + 2（откуда）· без / по́сле + 2。

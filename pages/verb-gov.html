怎么判断及物 / 不及物

别死记「及物=永远四格」。先问：这个动词后面能不能直接接 кого́? / что?（把谁 / 把什么）。能接，多半是及物；不能，就看它固定支配几格。

10 秒清单

  1. 能不能问 кого́? что?？能 → 通常及物 + 四格（如 чита́ть кни́гу）。
  2. 问不了「把谁/把什么」，却能问 кому́? / с кем? / где? → 不及物或固定支配，跟动词走。
  3. 查一眼例外表（下面）：否定、帮助、从事……经常不是四格。

常见例外（不是「永远四格」）

情况几格例记住
动词固定 + 三格 3 помога́ть дру́гу · звони́ть ма́ме 帮助 / 打电话 → кому́?
动词固定 + 五格 5 занима́ться спо́ртом · встреча́ться с дру́гом 从事 / 与谁 → чем? / с кем?
否定「没有」 2 Нет вре́мени. · У меня́ нет кни́ги. нет / не́ было → 二格
典型及物 4 ви́деть сестру́ · люби́ть му́зыку кого́? что? → 四格

口诀：先问 кого́?/что?；问不通就查支配；否定有/没有优先想二格。

18. 及物 / 不及物与格支配

怎么判断： 先问能不能接 кого́? / что?（把谁 / 把什么）。能 → 多半及物 + 四格；不能 → 跟动词固定支配（如 помога́ть + 三格、занима́ться + 五格）。否定「没有」常用二格（нет + 2），不是「永远四格」。

18.1 不及物例

учи́ться（学习，不及物）+ где?（六格）
- я учу́сь, ты у́чишься, он/она́ у́чится, мы у́чимся, вы у́читесь, они́ у́чатся
- -ся / -сь：元音后常用 -сь（учу́сь）

18.2 及物 + 四格

люби́ть, знать, слу́шать, смотре́ть, понима́ть, жда́ть / подожда́ть кого́? что?, де́лать, переводи́ть, петь, повторя́ть, фотографи́ровать …

18.3 双支配：что? (4) кому́? (3)

пока́зывать / показа́ть, расска́зывать / рассказа́ть, дава́ть / дать, броса́ть / бро́сить
例：броса́ть мяч ма́льчику（把球扔给男孩）

18.4 с кем? (5)

знакоми́ться, встреча́ться, сове́товаться, разгова́ривать, здоро́ваться, проща́ться …（见第 22 节）

18.5 поздравля́ть кого́? (4) с чем? (5)

祝贺某人（四格）某事（с + 五格）

10. 前置词

前置词 接格 典型提问 例
в / на 四格 куда? в общежи́тие, в столо́вую, на конце́рт
в / на 六格 где? в общежи́тии, на уро́ке, на метро́
из / с 二格 откуда? из шко́лы, из Москвы́, с ры́нка
к 三格 к кому́? к врачу́, к подру́ге
о / об / обо 六格 о ком? о чём? о нём, обо мне
с 五格 с кем? с чем? с дру́гом, чай с са́харом
без 二格 без чего́? без молока́
по́сле 二格 по́сле чего́? по́сле обе́да
у 二格 у кого́? у меня́ есть …
по （固定） по телефо́ну；смотре́ть по телеви́зору

из + 地名（笔记）： из Москвы́, из Новосиби́рска, из Росси́и, из Герма́нии, из Берли́на, из Англии, из Пеки́на, из Кита́я, из Шанха́я, из То́кио, из Фра́нции, из Пари́жа, из Ло́ндона, из Сиби́ри

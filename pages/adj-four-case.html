形容词第四格：只有一个性必须变

第四格是「直接宾语格」——动作直接落在谁/什么身上。形容词跟着名词走，所以先认清一件事：四格里，形容词只有四种长相，而且三种是「照抄一格」，只有阴性要动。

名词类型提问形容词词尾用 но́вый 举例是否变形
阳性非动物како́й?-ый / -ий / -ойви́жу но́вый дом不变，= 一格
阳性动物како́го?-ого / -егови́жу но́вого дру́га变，= 二格
中性како́е?-ое / -ееви́жу но́вое зда́ние不变，= 一格
阴性каку́ю?-ую / -ююви́жу но́вую кни́гу变，唯一真变的
复数каки́е? / 动物 каки́х?非动物 -ые/-ие；动物 -ых/-ихви́жу но́вые до́мы
ви́жу но́вых друзе́й		非动物 = 一格
动物 = 二格

一句话记住：四格里只有阴性一定换尾巴（-ая → -ую、-яя → -юю），其余全看「是不是活的」——死的照抄一格，活的抄二格。

你笔记上那一页，逐条对上

笔记里四格那四行写得很准，正好就是上表的四种情况：

笔记上的提问笔记上的例句解释
како́го? (4)люблю́ своего́ дру́га
уважа́ю хоро́шего ста́рого челове́ка		阳性动物。друг、челове́к 是活的，四格借二格：-ого / -его
како́й? (4)вспомина́ю свой родно́й дом阳性非动物。死物照抄一格，形容词原样不动
како́е? (4)ищу́ / нашёл свобо́дное ме́сто中性。无论死活（中性动物极少），照抄一格
каку́ю? (4)жду / встреча́ю / вспомина́ю мою́ бли́зкую хоро́шую подру́гу
свою́ родну́ю у́лицу		阴性。-ая → -ую、-яя → -юю，四个词一起变

笔记右下角那行 своего́ дру́га 与 свою́ подру́гу 的对比，就是把「阳性动物借二格、阴性走 -ую」摆在一起给你看。写的时候别把阳性那套 -ого 套到阴性上：люблю́ свою́ подру́гу，不是 своего́ подру́гу。

三种词干，尾巴对着换

四格只有阳性（动物）和阴性要换尾巴，所以只要记这两列的四种词干：

词干类型原形（一格阳性）阳性动物（=二格）阴性（四格）
硬词干но́выйно́вогоно́вую

г / к / х 词干ма́ленькийма́ленькогома́ленькую
软词干си́нийси́негоси́нюю
软词干 -нийле́тнийле́тнеголе́тнюю

ж / ш / ч / щ + 重音在尾большо́йбольшо́гобольшу́ю

三个写错频率最高的点：① ж ш ч щ 后面写 -его，不写 -ого（хоро́шего，写 хоро́шого 就错了）；② -ий 软词干写 -его / -юю（си́него / си́нюю）；③ большо́й 这类重音在词尾的，重音会跳到新尾巴上：большо́го / большу́ю。

物主代词和指示代词：同一个模子

四格题里只要看到「我的/你的/我们的/这个/那个」，把它们当形容词处理，尾巴一模一样。

一格阳非动物（=一格）阳动物（=二格）中性（=一格）阴性复数非动物 / 动物

两个陷阱：① наш / ваш 的阳性动物是 на́шего / ва́шего（重音在 а，不在尾巴），和 моего́ 相反；② 阴性四格只有 э́ту / ту / мою́ / на́шу 这几个短形式，写成 э́тую 是典型错。

哪些动词后面一定跟四格

四格是「直接宾语」，所以一看到这些动词，后面名词直接上四格，形容词跟着走：

动词意思例句
люби́ть爱、喜欢Я люблю́ ру́сскую му́зыку.
знать / понима́ть知道 / 明白Он зна́ет э́того студе́нта.
чита́ть / писа́ть读 / 写Мы чита́ем интере́сную кни́гу.
слу́шать / смотре́ть听 / 看Они́ смо́трят но́вый фильм.
ви́деть / встреча́ть看见 / 遇见Я встреча́ю ста́рого дру́га.
ждать等Она́ ждёт младшую сестру́.
иска́ть / находи́ть找 / 找到Он иска́л но́вую рабо́ту.
фотографи́ровать拍照Тури́сты фотографи́руют краси́вое о́зеро.
покупа́ть / зака́зывать买 / 点（菜）Мы зака́жем све́жую ры́бу.
изуча́ть学习、研究Студе́нты изуча́ют ру́сский язы́к.

注意 учи́ть（背、学）和 учи́ться（上学，无四格）不是一回事：Я учу́ но́вые слова́（背新词，四格）／Я учу́сь в университе́те（在大学读书，六格）。

六个最常错的

错对为什么
Я люблю́ краси́вая де́вушка.Я люблю́ краси́вую де́вушку.阴性四格 -ую，名词也跟着变 де́вушку
Я ви́жу но́вый дру́га.Я ви́жу но́вого дру́га.друг 是活的，阳性动物四格借二格
Он чита́ет интере́сная кни́га.Он чита́ет интере́сную кни́гу.四格阴性；名词也要变 кни́гу
Мы слу́шаем ру́сская му́зыка.Мы слу́шаем ру́сскую му́зыку.同上，形容词和名词一起进四格
Она́ ждёт моего́ сестру́.Она́ ждёт мою́ сестру́.сестра́ 是阴性，用 мою́；моего́ 只给阳性动物
Я ви́жу си́нее мо́ре → 改成 си́нее 就行Я ви́жу си́нее мо́ре.（本来就对）中性四格 = 一格，别多手动它

做四格题的固定动作：① 找动词，确认它支配四格；② 看宾语名词是阴是阳是中是复；③ 阳性和复数再问一句「活不活」；④ 形容词、物主代词、指示代词跟名词一起换。四步下来不会错。

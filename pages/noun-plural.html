4. 一格复数（名词复数）

4.1 规则词尾

性 单数结尾 → 复数 例
阳 硬辅音 -ы студе́нт → студе́нты, теа́тр → теа́тры
阳 -й / -ь；ж ш ч щ；г к х -и музе́й → музе́и, слова́рь → словари́, эта́ж → этажи́, врач → врачи́, парк → па́рки
阴 -а -ы ка́рта → ка́рты, страна́ → стра́ны
阴 -я / -ь；-ка/-га 等（拼写规则） -и пе́сня → пе́сни, пло́щадь → пло́щади, студе́нтка → студе́нтки, подру́га → подру́ги, вещь → ве́щи
中 -о -а окно́ → о́кна, ме́сто → места́
中 -е / -ие -я мо́ре → моря́, общежи́тие → общежи́тия

拼写口诀（笔记称「7 规则」）： 在 ж, ш, ч, щ 和 г, к, х 后写 -и，不写 -ы。
软性标记：-й, -я, -ь → 复数常走 -и。

4.2 不规则复数

单数 复数 义
друг друзья́ 朋友
брат бра́тья 兄弟
стул сту́лья 椅子
сын сыновья́ 儿子
дочь до́чери 女儿
сестра́ сёстры 姐妹
день дни 天
дом дома́ 房子
го́род города́ 城市
челове́к лю́ди 人 / 人们
ребёнок де́ти 孩子
я́блоко я́блоки 苹果

逃逸元音（词干元音脱落）：
- пода́рок → пода́рки（礼物）
- иностра́нец → иностра́нцы（外国人）

4.3 只有单数 / 只有复数 / 不变格

只有单数： еда́ 食物, лапша́ 面条, мя́со 肉, ры́ба 鱼, лук 洋葱, капу́ста 白菜, са́хар 糖, хлеб 面包, ма́сло 黄油

只有复数： часы́ 钟表/手表, очки́ 眼镜, де́ньги 钱, брю́ки 裤子, джи́нсы 牛仔裤, пельме́ни 饺子

几乎不变（indeclinable）： метро́, такси́, фото́ 等

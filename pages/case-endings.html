5. 二格词尾

提问：кого́? чего́?

5.1 单数

性 一格结尾 → 二格 例
阳/中 辅音 / -о -а брат → бра́та, журна́л → журна́ла, письмо́ → пи́сьма
阳/中 -й / -ь / -е -я слова́рь → словаря́, зада́ние → зада́ния
阳/中 -ие -ия （如 зада́ние 类）
阴 -а -ы сестра́ → сестры́
阴 г к х / ж ш ч щ 后的 -а -и подру́га → подру́ги
阴 -я / -ь -и тётя → тёти, пло́щадь → пло́щади
阴 -ия -ии （如 ле́кция → ле́кции）

特殊：
- мать → ма́тери；дочь → до́чери
- вре́мя → вре́мени；и́мя → и́мени
- оте́ц → отца́；кита́ец → кита́йца（逃逸元音）
- 以 -а/-я 结尾的阳性名词按阴性变：па́па → у па́пы, де́душка → у де́душки, дя́дя → у дя́ди

5.2 复数（词尾总结）

性 一格特征 → 二格复数 例
阳 硬辅音 -ов стол → столо́в
阳 -й -ев музе́й → музе́ев
阳 -ь；ж ш ч щ -ей слова́рь → словаре́й, врач → враче́й
阴 -а 零词尾 кни́га → книг
阴 -я -ь неде́ля → неде́ль
阴 -ь -ей ночь → ноче́й
中 -о 零词尾（常加 заполняющая о/е） окно́ → око́н, письмо́ → пи́сем
中 -е -ей мо́ре → море́й
中 -ие -ий упражне́ние → упражне́ний

5.3 二格常见用法（笔记中出现）

  • нет + 二格：нет вре́мени, нет де́нег, нет пробле́м
  • у кого?：у меня́, у тебя́, у него́, у неё, у нас, у вас, у них
  • после + 二格：по́сле за́втрака / обе́да / у́жина / экза́мена
  • без + 二格：вода́ без га́за, чай без са́хара, ко́фе без молока́
  • из / с + 二格（откуда）：из Москвы́, из Пеки́на, из Росси́и, из университе́та

5.4 数量与时间里的二格

数 名词用格 例
1 一格单 оди́н час / одна́ мину́та
2, 3, 4 二格单 два / три / четы́ре часа́；две / три / четы́ре мину́ты
5–20（及多数） 二格复 пять часо́в / пять мину́т
несколько 二格复 не́сколько мину́т / часо́в

年：1 год · 2–4 го́да · 5–20 лет / мно́го лет
- наза́д（……以前）：… наза́д
- че́рез（过……之后）：че́рез …

6. 三格词尾

提问：кому́? чему́?

6.1 名词单数

性 一格 → 三格 例
阳 辅音 -у друг → дру́гу
阳 -й / -ь -ю Андре́й → Андре́ю, преподава́тель → преподава́телю
阴 -а -е подру́га → подру́ге
阴 -я -е тётя → тёте
阴 -ия -ии Мари́я → Мари́и
阴 -ь -и （软阴）
中 -о -у письмо́ → письму́
中 -е -ю мо́ре → мо́рю

6.2 人称代词三格

мне · тебе́ · ему́ · ей · нам · вам · им

6.3 常接三格的动词（笔记）

звони́ть / позвони́ть, говори́ть / сказа́ть, дава́ть / дать, расска́зывать / рассказа́ть, помога́ть / помо́чь, дари́ть / подари́ть, сове́товать / посове́товать, пока́зывать / показа́ть, отвеча́ть / отве́тить, посыла́ть / посла́ть

典型结构：что? (4) кому́? (3) —— 如 пока́зывать / расска́зывать / броса́ть：把什么（四格）给谁（三格）。

7. 四格词尾

提问：кого́? что?

7.1 总规则

性 规则
阳 · 非动物 四格 = 一格
阳 · 动物 四格 = 二格
阴 -а → -у；-я → -ю；-ь 不变
中 四格 = 一格
复 · 非动物 四格 = 一格
复 · 动物 四格 = 二格

7.2 动物阳 / 阴例

一格 四格 说明
Ива́н Ива́на 辅音 → -а
Андре́й Андре́я -й → -я
преподава́тель преподава́теля -ь → -я
сестра́ сестру́ -а → -у
Мари́я Мари́ю -я → -ю
па́па па́пу 阳名词 -а 按阴变
дя́дя дя́дю 同上
ребёнок ребёнка 特例
оте́ц отца́ 逃逸元音
кита́ец кита́йца 逃逸元音

7.3 常接四格的动词（笔记）

знать, люби́ть, слу́шать, смотре́ть, понима́ть, ви́деть, фотографи́ровать, де́лать, перево́дить, петь, повторя́ть …

例：Это Ива́н. → Я хорошо́ зна́ю Ива́на.

8. 五格词尾

提问：кем? чем?

8.1 名词单数

性 一格 → 五格 例
阳/中 辅音 / -о -ом （如 преподава́тель → преподава́телем 见软干）
阳/中 -й / -е / -ь / -ие -ем / -ём и́мя → и́менем, вре́мя → вре́менем
阴 -а -ой
阴 -я -ей / -ёй
阴 -ия -ией
阴 -ь -ью дверь → две́рью
特殊 мать / дочь ма́терью / до́черью

8.2 用法（笔记）

  • 职业 / 成为：Кем вы хоти́те стать? · Я хочу́ стать худо́жником. · Она́ рабо́тает в МГУ преподава́телем. · Её ма́ма ра́ньше то́же была́ студе́нткой.
  • с + 五格（和……一起 / 带……）：вода́ с га́зом, чай с са́харом, ко́фе с молоко́м
  • 代词：со мной, с тобо́й, с ним, с ней, с на́ми, с ва́ми, с ни́ми

9. 六格词尾

提问：где? · о ком? о чём? · в/на ком? в/на чём?

9.1 名词单数（地点 / 谈论对象）

性 一格 → 六格 例
阳 辅音 / -й / -ь -е в Пеки́не, в Кита́е, в оте́ле
阴 -а / -я -е в Москве́, в дере́вне
阴 -ия -ии в Росси́и；о исто́рии
阴 -ь -и на пло́щади；о две́ри
中 -о / -е -е на окне́, на мо́ре
中 -ие -ии в общежи́тии

复数六格笔记提示：多数 → -ах / -ях 一类（课本表；此处按笔记「多数 → -е」旁注保留提醒，实际以课本完整表为准）。
-ий / -ия / -ие / 部分 -ь → -и：о исто́рии, о две́ри。

9.2 常与六格搭配的动词（地点）

жить, рабо́тать, учи́ться, отдыха́ть, гуля́ть, быть, быва́ть, находи́ться

例：Где вы живёте? · жить I：я живу́, ты живёшь, он/она́ живёт, мы живём, вы живёте, они́ живу́т。

9.3 о + 六格（关于）

обо мне, о тебе́, о нём, о ней, о нас, о вас, о них

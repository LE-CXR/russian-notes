二格：何时用

典型结构

  • нет / не́ было / не бу́дет + 2：есть музе́й ↔ нет музе́я；нет вре́мени · нет де́нег · нет пробле́м
  • у + 2（有）：у меня́ есть … — 见 есть/нет
  • по́сле + 2：по́сле за́втрака · по́сле обе́да · по́сле у́жина · по́сле экза́мена
  • бе́з + 2：чай без са́хара · вода́ без га́за
  • из / с + 2（从哪来）：из Москвы́ · из Кита́я · с ры́нка
  • 数量 2–4 / 5+：две кни́ги · пять книг

三格：何时用

常接三格的动词

звони́ть · помога́ть · дари́ть · дава́ть · говори́ть · расска́зывать · пока́зывать · отвеча́ть · посыла́ть · сове́товать · нра́виться（кому?）

双支配：что? (4) + кому́? (3) — Расскажи́ мне э́ту исто́рию! · Покажи́ мне фо́то! · броса́ть мяч ма́льчику

к + 3（去找谁）：к врачу́ · к подру́ге（对比 куда? в поликли́нику 四格）

变位与支配表 → 6. 三格词尾 · 动词→几格

四格：何时用

  • 及物 + 4：先问 кого́? что? — Чита́ю кни́гу · Пишу́ пи́сьма · Жду́ дру́га
  • куда́? + в/на + 4（方向）：见 方向三角
  • 动物阳 / 人（宾语）= 二格形：ви́жу Ива́на · зна́ю Андре́я
  • поступи́ть в + 4：поступи́ть в университе́т · пойти́ на рабо́ту · Как поступи́ть в вуз?

及物判断 → 怎么判断及物 · 词尾 → 7. 四格 · 变位 поступа́ть

五格：何时用

кем? — 职业 / 身份

Кем вы хотите стать? · Я хочу́ стать худо́жником. · Она́ рабо́тает в МГУ преподава́телем. · Она́ рабо́тает учи́тельницей уже́ 5 лет.

быть / стать / рабо́тать + кем? — 见 ну́жен 对照

с + 5 — 与谁一起 / 社交动词

с кем?：знако́миться · встреча́ться · сове́товаться · здоро́ваться · разгова́ривать · проща́ться — 详见 22. 社交动词 · 变位 сове́товаться

с / без — 带 / 不带

вода́ с га́зом ↔ вода́ без га́за · чай с са́харом ↔ чай без са́хара

词尾 → 8. 五格

六格：何时用

  • где? + в/на + 6：я в общежи́тии · уро́к в аудито́рии
  • о ком? о чём? + 6：ду́маю о тебе́ · о нём · о ней
  • на + 6（乘坐）：на авто́бусе · на метро́ · на маши́не · на велосипе́де — 15. 交通工具
  • 月份 / 季节（в + 6）：16. 时间表达

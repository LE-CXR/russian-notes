Урок 3 · 第二格 роди́тельный паде́ж

对应《走遍俄罗斯》第 2 册第 3 课（стр. 70）· 语法核心：二格单数 + свой 二格 + который 二格 + чтобы 复合句

二格是俄语使用频率最高的一格，因为它管着三件天天要做的事：说「谁的 / 什么的」、说「没有」、说「从哪来」。这三个功能再加上「数量」和「日期」，就构成了二格的全部。别把它当成一个格来背，当成五个固定结构来记会快得多。

意义提问标志例
① 领属与特征（谁的 / 什么样的）чей? чего?名词 + 名词кни́га бра́та · дом отца́ · челове́к де́ла
② 否定：没有кого́ нет? чего́ нет?нет / не́ было / не бу́детнет вре́мени · У меня́ нет кни́ги.
③ 起点：从哪来отку́да?из / с / отиз шко́лы · с рабо́ты · от дру́га
④ 数量ско́лько?2–4 / 5+ / мно́годва часа́ · пять лет · мно́го рабо́ты
⑤ 时间（日期、时段）когда́?二格日期 / до / по́сле / во вре́мяпе́рвого января́ · по́сле обе́да · до уро́ка

和第 2 课配成一对：Урок 2 讲 куда́（去哪里，四格），这一课讲 отку́да（从哪里来，二格）。идти́ в шко́лу（去学校，四格）↔ прийти́ из шко́лы（从学校回来，二格）。方向这一块，四格 + 二格两课合起来才完整。

阴性 -а 到底写 -ы 还是 -и

拼写规则决定，跟读音无关：词干以 г / к / х / ж / ш / ч / щ 结尾的写 -и，其余写 -ы。

кни́га → кни́ги · рука́ → руки́ · де́вушка → де́вушки · страна́ → страны́ · ка́рта → ка́рты · рабо́та → рабо́ты

这是七字母规则（г, к, х, ж, ш, ч, щ 后不写 ы），和第 1 课一格复数同一条规则。

из / с / от 三选一（本课最大的坑）

从哪来用哪个例
从封闭空间里面изиз до́ма · из шко́лы · из магази́на · из Кита́я
从表面 / 从某个活动或地点（习惯说法）ссо стола́ · с рабо́ты · с уро́ка · с ры́нка · с по́чты
从某人那里отот врача́ · от дру́га · от роди́телей

рабо́та、уро́к、по́чта、ры́нок 这几个词习惯用 с，不用 из，要单独记。反过来说，从医院（из больни́цы）、从大学（из университе́та）用 из。

三、否定与数量：二格的两个高频结构

1. 没有 = нет + 二格

时态结构例
现在нет + 二格У меня́ нет вре́мени. · В го́роде нет метро́. · Нет вопро́сов?
过去не́ было + 二格Вчера́ у меня́ не́ было уро́ка. · Не́ было дожди́.
将来не бу́дет + 二格За́втра не бу́дет заня́тий.

肯定 ↔ 否定要成对记：

У меня́ есть кни́га. ↔ У меня́ нет кни́ги.
В го́роде есть музе́й. ↔ В го́роде нет музе́я.
У нас есть вре́мя. ↔ У нас нет вре́мени.

2. 数量 + 二格

数量词后面接例
1 (оди́н / одна́ / одно́)一格单数оди́н час · одна́ кни́га
2–4 (два, три, четы́ре)二格单数два часа́ · три го́да · четы́ре кни́ги
5 以上二格复数пять часо́в · шесть лет · де́сять книг
мно́го / ма́ло / не́сколько / ско́лько二格复数мно́го друзе́й · ма́ло вре́мени · ско́лько лет

注意：2–4 是「二格单数」不是复数，这是俄语数词最反直觉的地方。два го́да（两年，二格单数）、пять лет（五年，二格复数）。另外 год 的二格复数是特殊的 лет，不写 годов。

四、чтобы 复合句

чтобы 连接「愿望、目的、要求」，后面一律用过去时形式，而且不随主句时态变。这是本课唯一的新句式。

用法一：我想让某人做某事

Я хочу́, что́бы ты пришёл. — 我想让你来。
Ма́ма хо́чет, что́бы я хорошо́ учи́лся. — 妈妈想让我好好学习。
Оте́ц сказа́л, что́бы я не опа́здывал. — 爸爸让我别迟到。

对比：如果主句和从句主语是同一个，就不用 чтобы，直接用不定式——Я хочу́ прийти́.（我想来）。主语不同才用 чтобы。

用法二：表目的（为了……）

Что́бы хорошо́ говори́ть по-ру́сски, на́до мно́го занима́ться. — 为了俄语说得好，得多练。
Я прие́хал в Москву́, что́бы учи́ться. — 我来莫斯科是为了学习。

为什么用过去时？因为 чтобы 后面要的是一种「虚拟 / 设想」的形式，俄语用过去时来表达这个语气，与真实时间无关。что́бы ты пришёл 里的 пришёл 不是「你来了」，而是「你（去）来」。

五、который 的二格

角色形式例
所属（у + 二格）у кото́рого / у кото́рой / у кото́рыхВот студе́нт, у кото́рого есть слова́рь.
来源（из / с / от + 二格）из кото́рого / с кото́рой / от кото́рыхВот дом, из кото́рого он вы́шел.
否定（нет + 二格）кото́рого / кото́рой / кото́рыхВот кни́га, кото́рой нет в библиоте́ке.

规则还是老样子：性数跟先行词，格看它在从句里的角色。第 1 课练过六格，这一课换成二格，心里要清楚「为什么这里用二格」——因为从句里它站在 у / из / нет 后面。

六、30 个例句（全部标重音）

A. 领属与特征（8 句）

  1. Э́то кни́га моего́ бра́та. — 这是我哥哥的书。
  2. Мы сто́им у но́вого до́ма. — 我们站在新房子旁边。
  3. Он чита́ет стихи́ изве́стного поэ́та. — 他在读一位著名诗人的诗。
  4. Э́то центр го́рода. — 这是市中心。
  5. Я зна́ю сестру́ э́того студе́нта. — 我认识这个学生的妹妹。
  6. Дава́й встре́тимся у вхо́да в метро́. — 我们在地铁入口见吧。
  7. Э́то общежи́тие Моско́вского университе́та. — 这是莫斯科大学的宿舍。
  8. Кни́га лежи́т на краю́ стола́. — 书放在桌子边上。

B. 否定 нет / не было（7 句）

  1. У меня́ нет свобо́дного вре́мени. — 我没有空闲时间。
  2. В на́шем го́роде нет метро́. — 我们城市没有地铁。
  3. Вчера́ у нас не́ было уро́ка. — 昨天我们没有课。
  4. У бра́та нет моби́льного телефо́на. — 哥哥没有手机。
  5. За́втра не бу́дет дождя́. — 明天不会下雨。
  6. Нет вопро́сов? — 有问题吗？（没问题吧）
  7. У неё нет ру́чки. — 她没有笔。

C. 从哪来 отку́да?（6 句）

  1. Я пришёл из шко́лы. — 我从学校回来。
  2. Он верну́лся с рабо́ты. — 他下班回来了。
  3. Я получи́л письмо́ от дру́га. — 我收到朋友的信。
  4. Она́ прие́хала из Кита́я. — 她从中国来。
  5. Мы пришли́ с ры́нка. — 我们从市场回来。
  6. Он вы́шел из аудито́рии. — 他走出了教室。

D. 数量与时间（5 句）

  1. Я живу́ здесь два го́да. — 我在这里住了两年。
  2. Он рабо́тал там пять лет. — 他在那里工作了五年。
  3. В гру́ппе мно́го студе́нтов. — 班里有很多学生。
  4. Э́то бы́ло пе́рвого сентября́. — 那是九月一日。
  5. По́сле обе́да мы пошли́ гуля́ть. — 午饭后我们去散步了。

E. чтобы 与 который（5 句）

  1. Я хочу́, что́бы ты пришёл за́втра. — 我想让你明天来。
  2. Что́бы мно́го знать, на́до мно́го учи́ться. — 要想懂得多，就得学得多。
  3. Преподава́тель сказа́л, что́бы мы чита́ли э́тот текст. — 老师让我们读这篇课文。
  4. Вот студе́нт, у кото́рого есть э́тот слова́рь. — 这就是有这本词典的那位学生。
  5. Вот кни́га, кото́рой нет в на́шей библиоте́ке. — 这就是我们图书馆没有的那本书。

七、七个最容易错的地方

错误正确为什么

Я пришёл из рабо́ты.Я пришёл с рабо́ты.работа 习惯用 с，不用 из
Я получи́л письмо́ из дру́га.Я получи́л письмо́ от дру́га.从某人处用 от
два го́дов / пять го́дадва го́да / пять лет2–4 用二格单数，5+ 用二格复数；год 的复数二格是 лет
Я хочу́, что́бы ты придёшь.Я хочу́, что́бы ты пришёл.чтобы 后接过去时，不用将来时

自查三问（做二格题前默念）

  1. 这句是「谁的 / 没有 / 从哪来 / 多少 / 什么时候」里的哪一个？
  2. 前面是 нет、из/с/от、数词还是 много？——它决定了用不用二格。
  3. 是「从里面」还是「从表面 / 从某人」？из / с / от 选对了吗？

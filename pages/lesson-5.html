Урок 5 · 第五格 твори́тельный паде́ж

对应《走遍俄罗斯》第 2 册第 5 课（стр. 148）· 语法核心：五格单数 + свой 五格 + который 五格 + 直接引语转型

五格是「用什么、和谁、做什么身份」的一格，名字来自「工具」——最早就是表示用什么工具做事。后来扩展出「和谁一起」「以什么身份」「在什么上方/下方」等用法。提问词是 кем? чем?。

意义提问标志例
① 共同动作（和谁一起）с кем?с + 五格идти́ с дру́гом · говори́ть с ма́мой
② 职业与身份（当什么）кем?рабо́тать / стать / бытьрабо́тать врачо́м · стать инжене́ром
③ 从事与兴趣чем?занима́ться / интересова́тьсязанима́ться спо́ртом · интересова́ться му́зыкой
④ 工具（用什么）чем?动词 + 五格писа́ть ру́чкой · е́хать по́ездом
⑤ 位置（在上/下/前/后/之间）где?над / под / пе́ред / за / ме́жду / ря́дом снад столо́м · пе́ред до́мом
⑥ 时间когда?пе́ред / ме́ждупе́ред экза́меном · ме́жду уро́ками
⑦ 方式как?五格表方式говори́ть гро́мким го́лосом

和 шести格（六格）配对记位置类：в / на + 六格（在里 / 在上），而 над / под / пе́ред / за / ме́жду / ря́дом с 一律 + 五格。所以「书在桌上」是 на столе́（六格），「灯在桌上「方」」是 над столо́м（五格）。

重音决定 -ом 还是 -ем

ж / ш / ч / щ 结尾的词：重音在词尾写 -о́м，不在词尾写 -ем。

врач → врачо́м · каранда́ш → карандашо́м · ключ → ключо́м
това́рищ → това́рищем · плащ → плащо́м · оте́ц → отцо́м

二、с + 五格 与 без + 二格（必须成对背）

结构意义例
с + 五格和谁一起 / 带着什么идти́ с дру́гом · чай с са́харом · говори́ть с преподава́телем
без + 二格没有谁 / 没有什么чай без са́хара · идти́ без дру́га · ко́фе без молока́

这两个结构是同一件事的正反两面，考试常拿来做干扰项：с са́харом（加糖，五格）↔ без са́хара（不加糖，二格）。记忆时绑在一起念。

职业与身份：рабо́тать / стать / быть + 五格

Он рабо́тает врачо́м. — 他当医生。
Она́ хо́чет стать учи́тельницей. — 她想成为教师。
Мой оте́ц был инжене́ром. — 我父亲以前是工程师。

这三个动词后面的「身份」一律五格，不用一格。不要写 Он рабо́тает врач。

四、30 个例句（全部标重音）

A. с + 五格（和谁、带着什么）（8 句）

  1. Я иду́ в кино́ с свои́м дру́гом. — 我和朋友去看电影。
  2. Он живёт с роди́телями. — 他和父母住在一起。
  3. Я люблю́ чай с молоко́м, а он — без молока́. — 我喜欢加牛奶的茶，他喜欢不加的。
  4. Познако́мьтесь с на́шей но́вой студе́нткой. — 认识一下我们的新同学。
  5. Мы говори́ли с преподава́телем об экза́мене. — 我们和老师谈了考试的事。
  6. Она́ гуля́ет с соба́кой ка́ждое утро́. — 她每天早上遛狗。
  7. Я поздоро́вался с сосе́дом. — 我和邻居打了招呼。
  8. Он пришёл с пода́рком. — 他带着礼物来了。

B. 职业、从事、兴趣（7 句）

  1. Мой брат рабо́тает программи́стом. — 我哥哥是程序员。
  2. Она́ хо́чет стать врачо́м. — 她想成为医生。
  3. Я занима́юсь спо́ртом ка́ждый день. — 我每天运动。
  4. Он интересу́ется ру́сской исто́рией. — 他对俄罗斯历史感兴趣。
  5. Мы увлека́емся му́зыкой. — 我们酷爱音乐。
  6. Он хорошо́ владе́ет ру́сским языко́м. — 他俄语掌握得很好。
  7. Э́тот дом по́строен изве́стным архитекто́ром. — 这座房子是由一位著名建筑师建造的。

C. 工具与方式（5 句）

  1. Я пишу́ ру́чкой, а не карандашо́м. — 我用钢笔写，不是铅笔。
  2. Он ри́сует просты́м карандашо́м. — 他用普通铅笔作画。
  3. Мы е́хали по́ездом. — 我们是坐火车去的。
  4. Он говори́л гро́мким го́лосом. — 他用很大的声音说话。
  5. Она́ ре́зала хлеб но́жиком. — 她用刀切面包。

D. 位置：над / под / пе́ред / за / ме́жду（6 句）

  1. Над столо́м виси́т ла́мпа. — 桌子上方挂着一盏灯。
  2. Кот сиди́т под столо́м. — 猫坐在桌子底下。
  3. Мы стои́м пе́ред до́мом. — 我们站在房子前面。
  4. Авто́бус остано́вился за угло́м. — 公交车停在了拐角后面。
  5. Ме́жду уро́ками у нас переры́в. — 课间我们有休息。
  6. Ря́дом с на́шим до́мом есть парк. — 我们家旁边有个公园。

E. который 五格与综合（4 句）

  1. Вот де́вушка, с кото́рой я танцева́л. — 这就是和我跳舞的那位姑娘。
  2. Вот челове́к, с кото́рым я рабо́таю. — 这就是和我一起工作的人。
  3. Э́то авто́бус, кото́рым я е́зжу в университе́т. — 这就是我上大学坐的公交。
  4. Я познако́мился с де́вушкой, кото́рая хорошо́ говори́т по-ру́сски. — 我认识了一位俄语说得很好的姑娘。

自查三问（做五格题前默念）

  1. 这句是「和谁 / 用什么 / 当什么 / 在哪上/下/前/后」里的哪一个？
  2. 前置词是 с（五格）还是 без（二格）？
  3. 形容词和名词同格了吗？阳中 -ым/-им，阴 -ой/-ей。
